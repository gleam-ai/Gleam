Plan → Execute → Reflect

Every task runs through a closed loop: decompose into steps, execute with DAG concurrency, then self-score 0–100. Low scores trigger automatic replanning. No more forgotten follow-ups.

Local-first

Conversations, memory, tasks, and audit logs default to your machine. Only real LLM calls leave your network — and you pick the provider.

9 LLM providers

GLM, DeepSeek, Kimi, Qwen, OpenAI, Anthropic, OpenRouter, and more. Multi-model tier routing — use a strong model for planning, a fast one for summaries.

27 built-in tools

File, shell, web, git, clipboard, screenshots, memory, scheduling — plus MCP for unlimited extensions. Install from the marketplace in one click.

7 expert roles

Analyst, engineer, PM, researcher, ops, creator — or define your own. Each role brings its own system prompt, tool set, and model tier.

Skill crystallization

Successful executions become reusable, versioned skills with success-rate tracking. Failed runs auto-optimize parameters via LLM revision. Your workflows get better every time.
